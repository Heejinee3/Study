## immer

불변성(immutable) 상태 관리를 쉽게 해주는 JavaScript 라이브러리

불변성(immutable)이란 기존 객체를 직접 수정하지 않고 새 객체를 만들어 상태를 변경하는 것

깊은 객체를 업데이트할 때는 `immer`처럼 불변성을 자동으로 유지해주는 도구를 사용하면 중첩된 속성도 안전하고 간결하게 업데이트할 수 있음

```jsx
import { produce } from "immer";

const initialState = {
  todos: [{ id: 1, text: "Learn immer", done: false }],
};

const nextState = produce(initialState, (draft) => {
  draft.todos[0].done = true; // 직접 수정하는 것처럼 작성
});

console.log(nextState.todos[0].done); // true
console.log(initialState.todos[0].done); // false
```

## react-virtualized

대용량 리스트나 테이블을 효율적으로 렌더링할 수 있게 도와주는 React 라이브러리

일반적인 방식으로 모든 데이터를 한 번에 렌더링하면 수천~수만 개 항목에서 성능 문제가 발생하는데, `react-virtualized`는 보이는 영역만 렌더링하기 때문에 성능이 월등히 좋아짐

| 컴포넌트       | 설명                                  |
| -------------- | ------------------------------------- |
| List           | 스크롤 가능한 단일 컬럼 리스트        |
| Grid           | 행과 열이 있는 그리드 형태            |
| Table          | 컬럼, 헤더, 정렬 등을 지원하는 테이블 |
| AutoSizer      | 컨테이너 크기를 자동으로 감지         |
| WindowScroller | 전체 페이지 스크롤과 연동             |

```jsx
import React from "react";
import { List } from "react-virtualized";

const rowCount = 1000;
const rowHeight = 40;
const width = 300;
const height = 400;

const MyList = () => {
  const rowRenderer = ({ key, index, style }) => (
    <div key={key} style={style}>
      Row #{index}
    </div>
  );

  return (
    <List
      width={width}
      height={height}
      rowCount={rowCount}
      rowHeight={rowHeight}
      rowRenderer={rowRenderer}
    />
  );
};

export default MyList;
```
