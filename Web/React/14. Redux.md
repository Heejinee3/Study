## Redux란

전역 상태 관리 라이브러리

리액트 앱에서 여러 컴포넌트가 공유하는 데이터를 한 곳(Store)에 모아 관리하도록 도와줌

<br />

## 설치

```jsx
npm install redux react-redux
```

<br />

## 원칙

1. 단일 store

   모든 상태는 하나의 store 객체 안에 저장

2. 읽기 전용 상태

   상태를 직접 수정할 수 없으며, 값을 바꾸려면 action을 통해 요청해야 함

3. reducer는 순수한 함수

   순수 함수: 같은 입력을 넣으면 항상 같은 결과를 내고, 함수 밖의 상태를 절대 변경하지 않는 함수

<br />

## 핵심 개념

### Store

상태(state)가 저장되는 유일한 장소

앱 전체에서 단 하나만 존재함

`createStore()`로 생성

<br />

### State

Store 안에 저장된 데이터 자체

직접 수정 불가하며 항상 reducer를 통해서만 변경됨

<br />

### Action

“무슨 일을 할 건지” 설명하는 객체

`type` 필드는 반드시 가지고 있어야 함

ex. `{ type: 'INCREMENT', payload: 3 }`

<br />

### Reducer

상태를 실제로 변경하는 함수

순수 함수여야 함

형태: `(state, action) => newState`

<br />

### Dispatch

액션을 스토어에 전달하는 함수

디스패치를 호출해야만 상태가 변경됨

ex. `store.dispatch({ type: "INCREMENT" });`

<br />

### Subscribe

상태가 변경될 때마다 호출될 함수 등록

UI 업데이트나 로그 출력할 때 사용

ex.

```jsx
store.subscribe(() => {
  console.log("state changed:", store.getState());
});
```

<br />

## 예시

```jsx
import { createStore } from "redux";

// 1. reducer 정의
function counter(state = { value: 0 }, action) {
  switch (action.type) {
    case "INCREMENT":
      return { value: state.value + 1 };
    case "DECREMENT":
      return { value: state.value - 1 };
    default:
      return state;
  }
}

// 2. store 생성
const store = createStore(counter);

// 3. subscribe 등록
store.subscribe(() => console.log(store.getState()));

// 4. action dispatch
store.dispatch({ type: "INCREMENT" }); // { value: 1 }
store.dispatch({ type: "INCREMENT" }); // { value: 2 }
store.dispatch({ type: "DECREMENT" }); // { value: 1 }
```
