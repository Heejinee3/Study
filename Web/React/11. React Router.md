## 개념

리액트(React) 앱에서 페이지 이동(라우팅)을 가능하게 해주는 라이브러리

한 페이지(SPA, Single Page Application)로 동작하는 리액트 앱에서 주소가 바뀌어도 새로고침 없이 필요한 컴포넌트만 교체

<br />

## 설치

```jsx
npm install react-router-dom
```

<br />

## 기본 동작

```jsx
import { BrowserRouter, Routes, Route } from "react-router-dom";
import Home from "./Home";
import About from "./About";
import Profile from "./Profile";

function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Home />} /> {/* 메인 페이지 */}
        <Route path="/about" element={<About />} /> {/* 소개 페이지 */}
        <Route path="/profile/:id" element={<Profile />} /> {/* 동적 라우트 */}
      </Routes>
    </BrowserRouter>
  );
}

export default App;
```

## 주요 기능

### &lt;BrowserRouter&gt;

라우팅 기능을 전체 앱에 적용하는 최상위 컴포넌트

```jsx
import { BrowserRouter } from "react-router-dom";

function App() {
  return (
    <BrowserRouter>
      <div>라우팅 적용된 앱</div>
    </BrowserRouter>
  );
}
```

<br />

### &lt;Route&gt;와 &lt;Routes&gt;

`<Route>` : 특정 경로(path)에 어떤 컴포넌트를 보여줄지 정의

`<Routes>` : 여러 `<Route>`들을 묶는 컨테이너

```jsx
import { BrowserRouter, Routes, Route } from "react-router-dom";

function Home() {
  return <h1>홈</h1>;
}

function About() {
  return <h1>소개</h1>;
}

function NotFound() {
  return <h1>페이지를 찾을 수 없습니다</h1>;
}

function App() {
  return (
    <BrowserRouter>
      <Routes>
        {/* 기본 경로 ("/") */}
        <Route index element={<Home />} />

        <Route path="/about" element={<About />} />

        {/* 어떤 경로와도 일치하지 않을 때 */}
        <Route path="*" element={<NotFound />} />
      </Routes>
    </BrowserRouter>
  );
}
```

<br />

### &lt;Link&gt;

클릭 시 새로고침 없이 페이지 이동

```jsx
import { Link } from "react-router-dom";

function Navbar() {
  return (
    <nav>
      <Link to="/">홈</Link>
      <Link to="/about">소개</Link>
    </nav>
  );
}
```

### useParams와 useSearchParams

`useParams` : URL 파라미터를 가져옴

예시 URL: `/user/:id`

```jsx
// 라우트 설정
<Route path="/user/:id" element={<User />} />
```

```jsx
// 컴포넌트에서 값 가져오기
import { useParams } from "react-router-dom";

function User() {
  const { id } = useParams();
  return <h2>유저 ID: {id}</h2>;
}
```

<p></p>

`useSearchParams` : 쿼리스트링을 가져옴

예시 URL: `/user?id=123&mode=edit`

```jsx
// 컴포넌트에서 값 가져오기
import { useSearchParams } from "react-router-dom";

function User() {
  const [params] = useSearchParams();
  const id = params.get("id");
  const mode = params.get("mode");
  return (
    <div>
      ID: {id}, MODE: {mode}
    </div>
  );
}
```

### &lt;Outlet&gt;

페이지 안에 또 다른 페이지가 있는 구조를 만들 때 사용

```jsx
import { BrowserRouter, Routes, Route, Outlet, Link } from "react-router-dom";

function About() {
  return (
    <div>
      <h1>소개 페이지</h1>
      <nav>
        <Link to="team">팀</Link> | <Link to="company">회사</Link>
      </nav>

      {/* 하위 라우트가 이 자리에서 렌더링됨 */}
      <Outlet />
    </div>
  );
}

function Team() {
  return <h2>팀 소개</h2>;
}

function Company() {
  return <h2>회사 정보</h2>;
}

function App() {
  return (
    <BrowserRouter>
      <Routes>
        {/* 부모 라우트 */}
        <Route path="/about" element={<About />}>
          {/* 자식 라우트들 */}
          <Route path="team" element={<Team />} />
          <Route path="company" element={<Company />} />
        </Route>
      </Routes>
    </BrowserRouter>
  );
}
```

### useNavigate

버튼 클릭 / 이벤트 처리 중에 페이지를 이동

`replace`를 `true`로 설정하면 이전 페이지 기록을 덮어 씀 (`navigate("/dashboard", { replace: true });`)

```jsx
import { useNavigate } from "react-router-dom";

function LoginButton() {
  const navigate = useNavigate();

  const handleLogin = () => {
    navigate("/dashboard");
  };

  return <button onClick={handleLogin}>로그인</button>;
}
```

### &lt;NavLink&gt;

링크를 만들면서 현재 활성화된 페이지인지 상태를 알 수 있는 컴포넌트

`<Link>`는 단순히 클릭 시 페이지 이동이지만 `<NavLink>`는 현재 URL과 링크 경로를 비교해서 자동으로 `active` 상태를 부여할 수 있음

주로 메뉴, 탭, 네비게이션 바에서 사용

```jsx
import { NavLink } from "react-router-dom";

function Navbar() {
  return (
    <nav>
      <NavLink
        to="/"
        style={({ isActive }) => ({ color: isActive ? "red" : "black" })}
      >
        홈
      </NavLink>
      <NavLink
        to="/about"
        style={({ isActive }) => ({ color: isActive ? "red" : "black" })}
      >
        소개
      </NavLink>
    </nav>
  );
}
```

<br />

### &lt;Navigate&gt;

렌더링 시 즉시 다른 경로로 이동

버튼 클릭처럼 이벤트가 아니라 렌더링 조건에 따라 이동할 때 사용

```jsx
import { Navigate } from "react-router-dom";

function PrivateRoute({ isLoggedIn, children }) {
  if (!isLoggedIn) {
    return <Navigate to="/login" replace />;
  }
  return children;
}
```
