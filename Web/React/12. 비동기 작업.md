## Promise

### 정의

비동기 작업을 처리하기 위한 객체

| 메서드  | 설명                     |
| ------- | ------------------------ |
| resolve | 성공 시 호출             |
| reject  | 실패 시 호출             |
| then    | 성공 시 실행할 콜백 등록 |
| catch   | 실패 시 실행할 콜백 등록 |
| finally | 성공/실패 관계없이 실행  |

<br />

### 사용 방법

```jsx
const promise = new Promise((resolve, reject) => {
  // 비동기 작업 수행
  const success = true;

  if (success) {
    resolve("작업 성공!");
  } else {
    reject("작업 실패!");
  }
});
```

```jsx
promise
  .then((result) => {
    console.log(result); // 성공 시 "작업 성공!"
  })
  .catch((error) => {
    console.error(error); // 실패 시 "작업 실패!"
  })
  .finally(() => {
    console.log("항상 실행됨");
  });
```

<br />

### 예시

```jsx
function fetchData() {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      const data = { name: "Doreen", age: 20 };
      resolve(data);
    }, 2000); // 2초 후 데이터 반환
  });
}

fetchData()
  .then((data) => console.log("데이터:", data))
  .catch((err) => console.error("에러:", err));
```

## async / await

Promise를 더 간결하게 사용

```jsx
function fetchData() {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      const data = { name: "Doreen", age: 20 };
      resolve(data);
    }, 2000);
  });
}

async function getData() {
  const data = await fetchData();
  console.log("데이터:", data);
}

getData();
```

## axios

서버에 요청(GET, POST, PUT, DELETE 등)을 보내고, 응답을 받아서 비동기적으로 처리할 수 있음

<br />

### 설치

```jsx
npm install axios
```

<br />

### 사용법

```jsx
import axios from "axios";

axios
  .get("https://jsonplaceholder.typicode.com/posts/1")
  .then((response) => {
    console.log(response.data); // 응답 데이터
  })
  .catch((error) => {
    console.error(error); // 에러 처리
  });
```

```jsx
import axios from "axios";

async function fetchPost() {
  try {
    const response = await axios.get(
      "https://jsonplaceholder.typicode.com/posts/1"
    );
    console.log(response.data);
  } catch (error) {
    console.error("에러 발생:", error);
  }
}

fetchPost();
```

<br />

### 요청

| 메서드   | 설명                  | 예시                                            |
| -------- | --------------------- | ----------------------------------------------- |
| `get`    | 데이터 조회           | `axios.get('/users')`                           |
| `post`   | 새 데이터 추가        | `axios.post('/users', { name: 'Doreen' })`      |
| `put`    | 기존 데이터 전체 수정 | `axios.put('/users/1', { name: 'Doreen Kim' })` |
| `patch`  | 기존 데이터 일부 수정 | `axios.patch('/users/1', { age: 21 })`          |
| `delete` | 데이터 삭제           | `axios.delete('/users/1')`                      |

<br />

### 응답

```jsx
response = {
  data: {}, // 서버가 실제로 보낸 데이터
  status: 200, // HTTP 상태 코드
  statusText: "OK",
  headers: {}, // 응답 헤더
  config: {}, // 요청에 사용된 설정
  request: {}, // 요청 객체
};
```
