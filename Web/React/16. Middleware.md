## Middleware

- 어떤 작업을 중간에서 가로채서 처리하는 코드
- reducer 호출 이전에 미들웨어에서 작업 처리
- 비동기 처리, 로그 찍기, 조건 처리, 필터링 가능

```jsx
Action → Middleware1 → Middleware2 → ... → Reducer → Store
```

<br />

## Custom Middleware (직접 만들기)

### 형태

```jsx
const middleware = (store) => (next) => (action) => {
  // 미들웨어 기본 구조
};
```

`store` : 전체 상태 접근

`next` : 다음 미들웨어 or reducer로 넘김

`action` : 지금 들어온 액션

<br />

### 예시

```jsx
store.dispatch(action) 호출
    ↓
미들웨어 체인 시작
    ↓
simpleLogger 실행
    ↓
console.log(action)
    ↓
next(action) 호출
    ↓
reducer 실행
    ↓
state 변경
```

```jsx
// simpleLogger.js

const simpleLogger = store => next => action => {
  console.log('dispatch된 action:', action)
  next(action)
}

default export simpleLogger
```

```jsx
// store.js

import simpleLogger from "./simpleLogger";
import reducer from "./reducer";
import { createStore, applyMiddleware } from "redux";

const store = createStore(reducer, applyMiddleware(simpleLogger));

export default store;
```

## Redux Logger

- Redux에서 dispatch되는 action과 state 변화를 콘솔에 자동으로 찍어주는 미들웨어

<br />

### 설치

```bash
npm install redux-logger
```

<br />

### 역할

`action`, `prev state`, `next state`를 console에 나타냄

```jsx
const logger = (store) => (next) => (action) => {
  console.log("action:", action);
  console.log("prev state:", store.getState());
  next(action);
  console.log("next state:", store.getState());
};
```

<br />

### 사용법

```jsx
// store.js

import { createStore, applyMiddleware } from "redux";
import logger from "redux-logger";
import reducer from "./reducer";

const store = createStore(reducer, applyMiddleware(logger));

export default store;
```

## Redux Thunk

- Redux에서 비동기 로직(예: API 호출)을 처리하기 위한 미들웨어
- Redux의 기본 규칙은 action은 순수 객체({ type: ‘xxx’ })여야 하고 reducer은 동기적으로만 동작해야 함
- 그러나 실제로는 비동기 작업이 필요함
  - 서버 API 호출
  - 일정 시간 후 dispatch
  - 조건에 따른 action dispatch
- 함수 형태의 action을 dispatch

<br />

### 설치

```jsx
npm install redux-thunk
```

<br />

### 역할

`action`이 함수면 실행하고 객체면 다음 `middleware` (또는 `reducer`)로 보냄

```jsx
const thunk = (store) => (next) => (action) => {
  if (typeof action === "function") {
    return action(store.dispatch, store.getState);
  }
  next(action);
};
```

<br />

### 사용법

```jsx
dispatch(fetchUser())
   ↓
thunk 미들웨어
   ↓
action 함수 실행
   ↓
dispatch(FETCH_USER_REQUEST)
   ↓
API 호출
   ↓
dispatch(FETCH_USER_SUCCESS)
   ↓
reducer
   ↓
state 업데이트
```

```jsx
// reducer.js

const initialState = {
  loading: false,
  user: null,
  error: null,
};

const reducer = (state = initialState, action) => {
  switch (action.type) {
    case "FETCH_USER_REQUEST":
      return { ...state, loading: true };

    case "FETCH_USER_SUCCESS":
      return { loading: false, user: action.payload, error: null };

    case "FETCH_USER_FAIL":
      return { loading: false, user: null, error: action.error };

    default:
      return state;
  }
};

export default reducer;
```

```jsx
// store.js

import { createStore, applyMiddleware } from "redux";
import thunk from "redux-thunk";
import reducer from "./reducer";

const store = createStore(reducer, applyMiddleware(thunk));

export default store;
```

```jsx
// actions.js

export const fetchUser = () => {
  return async (dispatch) => {
    // (dispatch, getState)도 가능
    dispatch({ type: "FETCH_USER_REQUEST" });

    try {
      const res = await fetch("https://jsonplaceholder.typicode.com/users/1");
      const data = await res.json();

      dispatch({
        type: "FETCH_USER_SUCCESS",
        payload: data,
      });
    } catch (err) {
      dispatch({
        type: "FETCH_USER_FAIL",
        error: err.message,
      });
    }
  };
};
```

## Redux Saga

- Generator 함수를 이용해 비동기 로직을 마치 동기 코드처럼 읽기 쉽게 작성하도록 도와주는 라이브러리
- Generator는 JavaScript의 yield를 이용해 함수를 중간에서 멈췄다가 다시 실행 가능
- Saga는 이를 이용해 비동기 코드를 단계별로 컨트롤

<br />

### 생명주기

1. 앱 초기화
   - Redux store 생성
   - Saga 미들웨어 연결
2. rootSaga 실행 (sagaMiddleware.run)
   - watcher saga 등록 (takeEvery, takeLatest, take)
   - rootSaga 안에 있는 모든 saga 동시 실행 (all 사용 시)
3. 액션 dispatch
   - watcher saga가 감지
   - worker saga 실행

```jsx
앱 시작
   ↓
Redux store 생성
   ↓
sagaMiddleware.run(rootSaga)
   ↓
rootSaga -> all([...watcher saga])
   ↓
watcher saga가 액션 감시 중 (take, takeEvery, takeLatest)
   ↓
액션이 dispatch되면 watcher saga → worker saga 실행
```

<details>
    <summary> 참고 (Saga와 Reducer 로직) </summary>

```jsx
[ JS call stack ]

dispatch(action)
↓
saga middleware ← 감지, task 생성
↓
next(action) ← 다음 미들웨어 or reducer로 넘김

[/] ← dispatch 종료, call stack 비워짐

↓

[saga scheduler]

saga worker ← 비동기 로직 진행

[/]

```

</details>

<br />

### Saga 종류

| 종류         | 역할                                  |
| ------------ | ------------------------------------- |
| worker saga  | 실제 API 호출, state 업데이트 등 처리 |
| watcher saga | 특정 액션 감시, worker 호출           |
| root saga    | 모든 saga 모아서 실행                 |

```jsx
// worker saga
function* fetchUserSaga() { ... }
function* fetchPostsSaga() { ... }

// watcher saga
function* userSaga() {
  yield takeLatest('GET_USER', fetchUserSaga);
}
function* postSaga() {
  yield takeLatest('GET_POSTS', fetchPostsSaga);
}

// root saga
export default function* rootSaga() {
  yield all([
    userSaga(),
    postSaga(),
  ]);
}
```

<br />

### Effect 종류

**`take`**

```jsx
yield take('FETCH_REQUEST');
```

- 특정 액션이 올 때까지 대기
- 한 번만 받음

<br />

**`takeEvery`**

```jsx
yield takeEvery('FETCH_REQUEST', fetchSaga);
```

- 액션 올 때마다 모두 실행
- 요청 병렬 처리

<br />

**`takeLatest`**

```jsx
yield takeLatest('FETCH_REQUEST', fetchSaga);
```

- 이전 작업 취소
- 최신 요청만 처리

<br />

**`put`**

```jsx
yield put({ type: 'SUCCESS' });
```

- 액션을 dispatch
- 액션을 dispatch만 하고 바로 다음 줄 실행

<br />

**`call`**

```jsx
yield call(api.fetchUser, id);
```

- 함수 실행 (보통 API)
- blocking

<br />

**`fork`**

```jsx
yield fork(backgroundTask);
```

- non-blocking
- 백그라운드 실행
- fork된 작업이 끝날 때까지 대기

<br />

**`cancel`**

```jsx
yield cancel(task);
```

- 실행 중인 saga 취소

<br />

**`all`**

```jsx
yield all([
  call(fetchUser),
  call(fetchPosts),
]);
```

- 여러 effect를 병렬 실행
- 전부 끝나야 다음 줄로 넘어감
- 하나라도 에러나면 전체 실패

<br />

**`delay`**

```jsx
yield delay(1000);
```

- 일정 시간 대기

<br />

**`select`**

```jsx
const user = yield select(state => state.user);
```

- Redux state 읽기

### 사용법

```jsx
// actions.js

export const FETCH_TODO = "FETCH_TODO";
export const FETCH_TODO_SUCCESS = "FETCH_TODO_SUCCESS";
export const FETCH_TODO_FAILURE = "FETCH_TODO_FAILURE";
```

```jsx
// reducer.js

import { FETCH_TODO_SUCCESS, FETCH_TODO_FAILURE } from "./actions";

const initialState = {
  todo: null,
  error: null,
};

export default function reducer(state = initialState, action) {
  switch (action.type) {
    case FETCH_TODO_SUCCESS:
      return { ...state, todo: action.payload, error: null };

    case FETCH_TODO_FAILURE:
      return { ...state, error: action.payload };

    default:
      return state;
  }
}
```

```jsx
// saga.js

import { takeEvery, call, put } from "redux-saga/effects";
import { FETCH_TODO, FETCH_TODO_SUCCESS } from "./actions";

function fetchTodoApi() {
  return fetch("https://jsonplaceholder.typicode.com/todos/1").then((res) =>
    res.json()
  );
}

function* fetchTodo() {
  const data = yield call(fetchTodoApi);
  yield put({ type: FETCH_TODO_SUCCESS, payload: data });
}

export default function* saga() {
  yield takeEvery(FETCH_TODO, fetchTodo);
}
```

```jsx
// store.js

import { createStore, applyMiddleware } from "redux";
import createSagaMiddleware from "redux-saga";
import reducer from "./reducer";
import saga from "./saga";

const sagaMiddleware = createSagaMiddleware();

const store = createStore(reducer, applyMiddleware(sagaMiddleware));

sagaMiddleware.run(saga);

export default store;
```
