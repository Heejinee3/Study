## Context

컴포넌트 간에 데이터를 전역적으로 공유하기 위한 방법

부모 → 자식으로 props를 계속 전달해야 하는 props drilling 문제를 해결

<br />

## 사용법

### 1. Context 생성

```jsx
import { createContext } from "react";

export const LanguageContext = createContext("한국어");
```

<br />

### 2. Provider

```jsx
import { useState } from "react";
import { LanguageContext } from "./LanguageContext";
import Child from "./Child";

function App() {
  const [language, setLanguage] = useState("한국어");

  const toggleLanguage = () => {
    setLanguage((prev) => (prev === "한국어" ? "English" : "한국어"));
  };

  return (
    <LanguageContext.Provider value={{ language, toggleLanguage }}>
      <Child />
    </LanguageContext.Provider>
  );
}

export default App;
```

<br />

### 3. Consumer

`방법 1. Consumer 사용`

- 함수형/클래스형 둘 다 가능
- 렌더링 시 Context 값을 함수 인자로 전달받음
- 코드가 조금 장황하지만 React 16 이전 버전 호환

```jsx
import { LanguageContext } from "./LanguageContext";

function Child() {
  return (
    <LanguageContext.Consumer>
      {({ language, toggleLanguage }) => (
        <div>
          <p>현재 언어: {language}</p>
          <button onClick={toggleLanguage}>언어 변경</button>
        </div>
      )}
    </LanguageContext.Consumer>
  );
}

export default Child;
```

<br />

`방법 2. useContext 사용`

- 가장 많이 쓰는 최신 방식
- 코드가 깔끔하고 직관적
- 함수형 컴포넌트 전용

```jsx
import { useContext } from "react";
import { LanguageContext } from "./LanguageContext";

function Child() {
  const { language, toggleLanguage } = useContext(LanguageContext);

  return (
    <div>
      <p>현재 언어: {language}</p>
      <button onClick={toggleLanguage}>언어 변경</button>
    </div>
  );
}

export default Child;
```

<br />

`방법 3. static contextType 사용`

- 클래스형 컴포넌트에서 Context 접근할 때 사용
- this.context로 바로 접근 가능
- 한 클래스에 하나의 Context만 연결 가능

```jsx
import React from "react";
import { LanguageContext } from "./LanguageContext";

class Child extends React.Component {
  static contextType = LanguageContext;

  render() {
    const { language, toggleLanguage } = this.context;
    return (
      <div>
        <p>현재 언어: {language}</p>
        <button onClick={toggleLanguage}>언어 변경</button>
      </div>
    );
  }
}

export default Child;
```
