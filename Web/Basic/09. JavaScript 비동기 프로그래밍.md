## promise

- Pending : 작업 진행 중(아직 결과 없음)
- Fulfilled : 작업 성공 → `resolve()` → `.then()` 실행
- Rejected : 작업 실패 → `reject()` → `.catch()` 실행

```jsx
// 선언
const promise = new Promise((resolve, reject) => {
  let success = true;

  if (success) {
    resolve("성공!");
  } else {
    reject("실패!");
  }
});

// 실행
promise
  .then((result) => {
    console.log(result); // 성공!
  })
  .catch((error) => {
    console.log(error); // 실패!
  });
```

```jsx
// Promise chaining
// return을 통해 값을 넘겨 받음
new Promise((resolve) => {
  resolve(1);
})
  .then((num) => num + 1)
  .then((num) => num * 2)
  .then((num) => console.log(num)); // 4

// return 값이 promise일 경우: Promise가 완료될 때까지 기다린 후의 resolve 값을 넘겨 받
new Promise((resolve) => {
  resolve(1);
})
  .then((num) => {
    return new Promise((resolve) => {
      resolve(num + 1);
    });
  })
  .then((num) => {
    return new Promise((resolve) => {
      resolve(num * 2);
    });
  })
  .then((num) => {
    console.log(num);
  });
```

## fetch

```jsx
fetch("https://jsonplaceholder.typicode.com/users/1")
  .then((response) => {
    return response.json();
  })
  .then((data) => {
    console.log(data.name);
  })
  .catch((error) => {
    console.error(error);
  });
```

## async / await

```jsx
function getData() {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      resolve("데이터 가져오기 완료");
    }, 2000);
  });
}

async function main() {
  const result = await getData();
  console.log(result);
}

main();
```
