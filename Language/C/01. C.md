## 타입

| 자료형   | 설명                                         | 크기(일반적)     |
| -------- | -------------------------------------------- | ---------------- |
| char     | 문자 1개를 저장                              | 1Byte            |
| short    | 작은 범위의 정수 저장                        | 2Byte            |
| int      | 정수를 저장                                  | 4Byte            |
| long     | 큰 범위의 정수 저장                          | 4Byte 또는 8Byte |
| float    | 단정밀도 실수 저장                           | 4Byte            |
| double   | 배정밀도 실수 저장                           | 8Byte            |
| signed   | 부호 있는 정수형(양수/음수)                  | -                |
| unsigned | 부호 없는 정수형(0과 양수)                   | -                |
| void     | 값이 없음을 의미하며 함수의 반환형 등에 사용 | -                |

## 연산자

| 연산자 종류       | 연산자                 | 설명                                     |
| ----------------- | ---------------------- | ---------------------------------------- |
| 산술 연산자       | +, -, \*, /, %         | 덧셈, 뺄셈, 곱셈, 나눗셈, 나머지 계산    |
| 증감 연산자       | ++, --                 | 변수의 값을 1 증가 또는 1 감소           |
| 대입 연산자       | =, +=, -=, \*=, /=, %= | 변수에 값을 대입하거나 연산 후 대입      |
| 비교 연산자       | ==, !=, >, <, >=, <=   | 두 값을 비교하여 참(1) 또는 거짓(0) 반환 |

| 비트 연산자       | &, \|, ^, ~, <<, >>    | 비트 단위로 연산 수행                    |
| 조건(삼항) 연산자 | ?:                     | 조건에 따라 두 값 중 하나를 선택         |
| sizeof 연산자     | sizeof                 | 자료형이나 변수의 크기(Byte)를 반환      |

## 제어문

`if-else if-else문`

```c
#include <stdio.h>

int main() {
    int score = 90;

    if (score >= 90) {
        printf("A학점\n");
    } else if (score >= 80) {
        printf("B학점\n");
    } else if (score >= 70) {
        printf("C학점\n");
    } else {
        printf("F학점\n");
    }

    return 0;
}
```

<br />

`switch문`

```c
#include <stdio.h>

int main() {
    int menu = 2;

    switch (menu) {
        case 1:
            printf("아메리카노\n");
            break;
        case 2:
            printf("카페라떼\n");
            break;
        case 3:
            printf("카푸치노\n");
            break;
        default:
            printf("없는 메뉴\n");
    }

    return 0;
}
```

<br />

`for문`

```c
#include <stdio.h>

int main() {
    int i;

    for (i = 1; i <= 5; i++) {
        printf("%d\n", i);
    }

    return 0;
}
```

<br />

`while문`

```c
#include <stdio.h>

int main() {
    int i = 1;

    while (i <= 5) {
        printf("%d\n", i);
        i++;
    }

    return 0;
}
```

<br />

`do-while문`

```c

int main() {
    int i = 1;

    do {
        printf("%d\n", i);
        i++;
    } while (i <= 5);

```

## 함수

```c
#include <stdio.h>

void hello() {
    printf("Hello, C!\n");
}

int main() {
    hello();
    return 0;
}
```

| 변수 종류                         | 선언 위치           | 유효범위              | 저장 기간                             |
| --------------------------------- | ------------------- | --------------------- | ------------------------------------- |
| 지역 변수 (Local Variable)        | 함수 내부           | 선언된 함수(블록) 안  | 함수 종료 시 소멸                     |
| 전역 변수 (Global Variable)       | 함수 외부           | 프로그램 전체         | 프로그램 종료 시 소멸                 |
| 정적 변수 (Static Variable)       | 함수 내부 또는 외부 | 선언 위치에 따라 다름 | 프로그램 종료 시 소멸(값 유지)        |
| 레지스터 변수 (Register Variable) | 함수 내부           | 선언된 함수(블록) 안  | 함수 종료 시 소멸(레지스터 사용 권장) |

## 배열

```c

    int arr[5] = {10, 20, 30, 40, 50};

    for (int i = 0; i < 5; i++) {
        printf("%d ", arr[i]);
    }
```

```c
#include <stdio.h>

int main() {
    int arr[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 3; j++) {
            printf("%d ", arr[i][j]);
        }
        printf("\n");
    }

    return 0;
}
```

```c
}
```

## 메모리의 동적 할당

`malloc()`

필요한 크기만큼 메모리를 동적으로 할당

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int *p = (int *)malloc(sizeof(int));

    *p = 10;
    printf("%d\n", *p);

    free(p);

    return 0;
}
```

<br />

`calloc()`

메모리를 할당하고 모든 값을 0으로 초기화

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int *p = (int *)calloc(5, sizeof(int));

    for (int i = 0; i < 5; i++)
        printf("%d ", p[i]);

    free(p);

    return 0;
}
```

<br />

`realloc()`

이미 할당된 메모리의 크기를 변경

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int *p = (int *)malloc(3 * sizeof(int));

    p = (int *)realloc(p, 5 * sizeof(int));

    free(p);

    return 0;
}
```

<br />

`free()`

동적으로 할당한 메모리를 해제

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int *p = (int *)malloc(sizeof(int));

    *p = 100;
    printf("%d\n", *p);

    free(p);

    return 0;
}
```

## 문자 입출력

`getchar()`

한 글자 입력 받기 (stdin에서 문자 1개 읽음)

```c
char c = getchar();
```

<br />

`fgetc()`

파일에서 문자 1개 읽기

```c
FILE *fp = fopen("a.txt", "r");
char c = fgetc(fp);
fclose(fp);
```

<br />

`putchar()`

한 글자 출력

```c
putchar('A');
```

<br />

`fputc()`

파일에 문자 1개 쓰기

```c
FILE *fp = fopen("a.txt", "w");
fputc('A', fp);
fclose(fp);
```

<br />

`fgets()`

문자열 한 줄 입력 (공백 포함 + 개행까지)

```c
char str[100];
fgets(str, 100, stdin);
```

<br />

`puts()`

문자열 출력 + 자동 줄바꿈

```c
puts("hello");
```

<br />

`fputs()`

파일에 문자열 출력 (줄바꿈 자동 없음)

```c
FILE *fp = fopen("a.txt", "w");
fputs("hello", fp);
fclose(fp);
```

<br />

`scanf()`

형식 지정해서 입력 받기

```c
int a;
scanf("%d", &a);
```

<br />

`printf()`

형식 지정해서 출력

```c
printf("a = %d\n", a);
```

<br />

`fscanf()`

파일에서 형식 지정 입력

```c
FILE *fp = fopen("a.txt", "r");

fscanf(fp, "%d", &x);
fclose(fp);
```

<br />

`fprintf()`

파일에 형식 지정 출력

```c
FILE *fp = fopen("a.txt", "w");

fclose(fp);
```

## 문자열

```c
#include <stdio.h>

int main() {
    char str[] = "Hello";

    printf("%s\n", str);

    return 0;
}
```

<br />

`strlen()`

문자열의 길이를 반환하는 함수

```c
#include <stdio.h>
#include <string.h>

int main() {
    char str[] = "Hello";

    printf("%lu\n", strlen(str)); // 5

    return 0;
}
```

<br />

`strcat()`, `strncat()`

문자열을 이어 붙이는 함수

strncat()은 지정한 개수만큼만 붙임

```c
#include <stdio.h>
#include <string.h>

int main() {
    char str1[20] = "Hello ";
    char str2[] = "C";

    strcat(str1, str2);

    printf("%s\n", str1);   // Hello C

    return 0;
}
```

```c
#include <stdio.h>
#include <string.h>

int main() {
    char str1[20] = "Hello ";
    char str2[] = "World";

    strncat(str1, str2, 3);

    printf("%s\n", str1);   // Hello Wor

    return 0;
}
```

<br />

`strcpy()`, `strncpy()`

문자열을 복사하는 함수

strncpy()는 지정한 개수만큼만 복사

```c
#include <stdio.h>
#include <string.h>

int main() {
    char str1[] = "Hello";
    char str2[20];

    strcpy(str2, str1);

    printf("%s\n", str2);   // Hello

    return 0;
}
```

```c
#include <stdio.h>
#include <string.h>

int main() {
    char str1[] = "Hello";
    char str2[20];

    strncpy(str2, str1, 3);
    str2[3] = '\0';

    printf("%s\n", str2);   // Hel

    return 0;
}
```

<br />

`strcmp()`, `strncmp()`

두 문자열을 비교하는 함수

strncmp()는 지정한 개수만 비교

```c
#include <stdio.h>
#include <string.h>

int main() {
    char str1[] = "ABC";
    char str2[] = "ABC";

    printf("%d\n", strcmp(str1, str2));   // 0

    return 0;
}
```

```c
#include <stdio.h>
#include <string.h>

int main() {
    char str1[] = "ABCDE";
    char str2[] = "ABCXY";

    printf("%d\n", strncmp(str1, str2, 3));   // 0

    return 0;
}
```

<br />

`atoi()`, `atol()`, `atoll()`, `atof()`

문자열을 숫자로 변환하는 함수

- atoi() → int
- atol() → long
- atoll() → long long
- atof() → double

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    char str[] = "123";

    printf("%d\n", atoi(str));   // 123

    return 0;
}
```

<br />

`toupper()`, `tolower()`

toupper() → 소문자를 대문자로 변환

tolower() → 대문자를 소문자로 변환

```c
#include <stdio.h>
#include <ctype.h>

int main() {
    printf("%c\n", toupper('a'));   // A
		printf("%c\n", tolower('A'));   // a

    return 0;
}
```

## Struct

기본 문법

```c
#include <stdio.h>

struct Student {
    int num;
    char name[20];
    float score;
};

int main() {
    struct Student s = {1, "홍길동", 95.5};

    printf("%d\n", s.num);      // 1
    printf("%s\n", s.name);     // 홍길동
    printf("%.1f\n", s.score);  // 95.5

    return 0;
}
```

<br />

`typedef` 이용

```c
#include <stdio.h>

typedef struct {
    int num;
    char name[20];
    float score;
} Student;

int main() {
    Student s = {1, "홍길동", 95.5};

    printf("%s\n", s.name);   // 홍길동

    return 0;
}
```

<br />

구조체 포인터

```c
#include <stdio.h>

struct Student {
    int num;
};

int main() {
    struct Student s = {1};
    struct Student *p = &s;

    printf("%d\n", p->num);     // 1
    printf("%d\n", (*p).num);   // 1

    return 0;
}
```

## Union

여러 멤버가 하나의 메모리 공간을 공유하는 사용자 정의 자료형

| 구분   | 구조체(`struct`)               | 공용체(`union`)                 |
| ------ | ------------------------------ | ------------------------------- |
| 메모리 | 멤버마다 각각 할당             | 모든 멤버가 하나의 메모리 공유  |
| 저장   | 여러 멤버를 동시에 저장 가능   | 한 번에 하나의 멤버만 저장 가능 |
| 크기   | 모든 멤버 크기의 합(패딩 포함) | 가장 큰 멤버의 크기             |

```c
#include <stdio.h>

union Data {
    int num;
    char ch;
};

int main() {
    union Data data;

    data.num = 65;
    printf("%d\n", data.num);   // 65

    data.ch = 'A';
    printf("%d\n", data.num);   // 값이 변경됨(환경에 따라 다를 수 있음)

    return 0;
}
```

## Enum

관련된 상수들을 하나의 이름으로 묶어 사용하는 사용자 정의 자료형

```c
#include <stdio.h>

enum Week { MON, TUE, WED };
// enum Week { MON = 0, TUE = 1, WED = 2};

int main() {
    enum Week day = TUE;

    printf("%d\n", day);   // 1

    return 0;
}
```
